Async Rust: Future부터 프로덕션까지

발표자 소개

  • Microsoft SCHIE(Silicon and Cloud Hardware Infrastructure Engineering) 팀의 수석 펌웨어 아키텍트
  • 보안, 시스템 프로그래밍(펌웨어, 운영체제, 하이퍼바이저), CPU 및 플랫폼 아키텍처, C++ 시스템 분야를 다뤄 온 업계 베테랑
  • 2017년(@AWS EC2)부터 Rust를 사용하기 시작했고, 그 이후로 계속 이 언어를 깊이 좋아하게 됨

Rust의 비동기 프로그래밍을 깊이 있게 다루는 가이드입니다. 많은 async 튜토리얼이 tokio::main부터 시작하고 내부 동작은 대충 넘어가는 것과 달리, 이 가이드는 Future 트레잇, polling, 상태 머신 같은 기초 원리부터 이해를 쌓은 뒤, 실제 패턴, runtime 선택, 프로덕션에서 만나는 함정까지 단계적으로 다룹니다.

이 책이 적합한 독자

  • 동기 Rust 코드는 작성할 수 있지만 async가 헷갈리는 Rust 개발자
  • async/await는 알지만 Rust의 모델은 익숙하지 않은 C#, Go, Python, JavaScript 개발자
  • Future is not Send, Pin<Box<dyn Future>>, “왜 내 프로그램은 멈추지?” 같은 문제를 겪어본 사람

선수 지식

다음 주제에 익숙해야 합니다:

  • 소유권, 대여, 라이프타임
  • 트레잇과 제네릭(impl Trait 포함)
  • Result<T, E>와 ? 연산자 사용
  • 기본적인 멀티스레딩(std::thread::spawn, Arc, Mutex)

Async Rust 경험은 없어도 됩니다.

목차

Part I: Async가 작동하는 방식

  • 1. Rust에서 Async가 다른 이유 🟢 — 핵심 차이: Rust에는 내장 runtime이 없다
  • 2. Future 트레잇 🟡 — poll(), Waker, 그리고 전체 동작을 가능하게 하는 계약
  • 3. Poll은 어떻게 동작하는가 🟡 — polling 상태 머신과 최소 executor
  • 4. Pin과 Unpin 🔴 — 자기 참조 구조체에 pinning이 필요한 이유
  • 5. 상태 머신의 정체 🟢 — async fn에서 컴파일러가 실제로 생성하는 것

Part II: 생태계

  • 6. Future를 직접 만들기 🟡 — TimerFuture, Join, Select를 처음부터 구현하기

  • 8. Tokio 심화 🟡 — runtime 종류, spawn, 채널, 동기화 프리미티브
  • 9. Tokio가 맞지 않는 경우 🟡 — LocalSet, FuturesUnordered, runtime-agnostic 설계
  • 10. Async 트레잇 🟡 — RPITIT, dyn dispatch, trait_variant, async closure

Part III: 프로덕션 Async

  • 11. Streams와 AsyncIterator 🟡 — 비동기 반복, AsyncRead/Write, stream combinator
  • 12. 흔한 함정 🔴 — 프로덕션에서 실제로 터지는 9가지 버그와 회피법
  • 13. 프로덕션 패턴 🔴 — graceful shutdown, backpressure, Tower 미들웨어
